# Onboarding

## Objetivo

Este projeto implementa o editor mini com backend em Go e interface em WebView (Wails v2), priorizando uma UX minimalista.

## Primeiro contato

1. Leia `README.md` para contexto geral.
2. Consulte `STATUS.md` para o estado atual e pendências.
3. Verifique `project/specs/to-do/` para as próximas implementações.

## Estrutura importante

- `src/`: backend Go
- `frontend/`: UI web
- `project/decisions/`: ADRs
- `.cursor/rules/`: regras operacionais para IA

## Fluxo recomendado

1. Escolher uma spec em `project/specs/to-do/`.
2. Mover para `project/specs/doing/` ao iniciar.
3. Implementar, validar e mover para `project/specs/done/` após aprovação.
